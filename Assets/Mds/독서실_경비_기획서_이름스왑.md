# 게임 기획서 (GDD) — *(가제) 독서실 야간 경비*

버려진 독서실을 5일간 야간 경비하는 1인칭 관리실 생존 공포 게임 레퍼런스: Five Nights at Freddy’s 1·3, Sister Location · 엔진: Unity (HDRP 목표)

## 1. 게임 개요

| 항목 | 내용 |
| --- | --- |
| 장르 | 관리실 거점 생존 공포 (Point-of-Survival Horror) |
| 시점 | 1인칭 고정 시점 + 제한적 이동 (창고 진입 시) |
| 진행 | 5일(밤) 생존, 날이 갈수록 귀신·난이도 증가 |
| 배경 | 버려진 독서실 (한국 입시·공부 문화 모티프) |
| 엔진 | Unity **HDRP**(목표) — 리썰 컴퍼니식 그래픽. 부담 시 URP 폴백 |
| 핵심 톤 | 어두운 실내, 정적, 소리로 위치 추적, 자원 고갈 압박 |

### 플레이 구조 — 고정형 + 위기 이동

- **평소:** 플레이어는 관리실 밖으로 나가지 않는다. CCTV·창문(육안)·환기구 셔터·오디오(종)·전력만으로 방어.

- **위기:** 정전 등 특정 상황이 터지면, 위험을 무릅쓰고 **창고로 직접 이동**해 수리(시스터로케이션식 제한 이동 — **엎드려 기어가기**, Ballora Gallery와 동일).

- **창고런 = 5박자 시퀀스:** [결정]→[1막 창고 기어가기]→[2막 전기실 수리]→[3막 탈출]→[복귀]. freeze 3단계 — **통로 진입~수리완료=완전정지 / 탈출중=저속(AI down) / 복귀 후=정상.** 들어갈 땐 안전, 나올 땐 시간 흘러 탈출이 클라이맥스. 긴장 두 축 = ①관리실 농성 ②창고런.

## 2. 핵심 게임플레이 루프

- CCTV로 귀신들의 위치 감시

- 접근하는 귀신에 맞춰 **창문 감시 / 환기구 셔터 / 오디오(종)**로 방어

- 모든 방어는 **전력(배터리)**을 소모 → 자원 관리 트레이드오프

- 사고 발생(정전·오디오 고장·산소 마비) → **연쇄 붕괴** 대응

- 정전 시 창고로 이동해 브레이커 수리(이동 위험 구간)

- 오전 6시까지 생존 → 다음 날

## 3. 맵 구조

### 구역 목록

관리실(플레이어 거점) / 공부방1 / 공부방2 / 로비 / 화장실 / **창고(윤진 zone)** / **전기실(윤석 zone)** / 복도(허브) / 환풍구 라인

맵 레이아웃 + 방 연결(초록 문)은 유저 제공 도면 기준 확정. 복도는 관리실 **위쪽 벽**에 가로로 붙어 좌우로 흐름.

### 방 인접 관계 (3개 이동망)

**① 문(복도망):** 복도가 허브 — 거의 모든 방이 복도를 거쳐야 이동. - 화장실↔복도 · 로비↔복도 · 공부방1↔복도 · 공부방2↔복도 · 창고↔복도 · 관리실↔복도 - 복도 **직접 연결(복도 우회)**: 공부방1↔공부방2, 창고↔전기실

**② 환풍구망:** 공부방2 ↔ 화장실 ↔ 관리실 직선 라인. 화장실이 교차점. 관리실 진입부에 **셔터.** - **몸집 작은 귀신 공용 지름길**(현우 메인, 현승 가끔). **연호는 뚱뚱해서 사용 불가**(→ 항상 복도로만 = 예측 가능한 메인 빌런). - 복도를 우회하는 제2 동맥 → 단조로움 방지.

**③ 창고런 다이렉트:** 관리실 → 창고 **전용 통로**(복도 안 거침). 정전 시에만. 이후 창고↔전기실.

### 창고 / 전기실 — 창고런 동선

- **창고 = 윤진 zone** (CCTV “소리만”). 엎드려 기어가는 Ballora식 청각 스텔스.

- **전기실 = 윤석 zone** (CCTV 사각). 브레이커 수리 목적지.

- 동선: **관리실 → (다이렉트 통로) → 창고[윤진] → 전기실[윤석, 수리] → 복귀**

### 화장실 = 이중 사각 허브

- CCTV 없음(복도 사각) + 환풍구 교차점. 귀신이 여기서 사라지면 → 천장(환풍구)으로 빠지거나 창문에 등장. “어디서 사라졌나 = 누구인가” 추리 단서.

### 관리실 내부 구조 (FNAF3식, 시야 4구역)

**정면 3구역 + 후면 1구역.** 한 번에 한 구역만 봄(올린 패널/회전 시 다른 곳 못 봄 = 손부족). - **왼쪽:** 리셋 패널 (환기 / 오디오 리셋) - **가운데:** 컴퓨터(CCTV + 종 버튼) / CCTV 내리면 정면 **창문**(실루엣 확인) - **오른쪽:** 환풍구 + 셔터 + **불빛 버튼**(눌러야 현우 보임, FNAF1식 / 평소 어두움) - **후면(창고 통로):** 오른쪽 끝에서 **“뒤돌아보기” UI 버튼** → 후면 전환. 후면에선 **“앞으로” 버튼**으로 복귀. **창고 통로는 정전 시에만 진입 가능**(평소엔 잠김, 상태로 정전 여부 확인됨). - 시야 회전·패널 조작·후면 전환 = **전부 화면 전환** → armed 귀신 있으면 점프스케어(6장/§0.5).

### ⚠️ 용어 분리 (혼동 방지)

- **환풍구** = 귀신 이동로(셔터로 차단).

- **산소순환장치** = 생명유지 환기 시스템. **김욱이 마비** → 질식. **리셋으로 복구.**

- 둘은 완전히 다른 시스템이다.

## 5. 핵심 시스템

### ① 전력 (배터리) — “방전”과 “배선 고장”은 다른 사건

- 종·셔터·CCTV·조명·환기가 **공통 배터리** 소모.

- **배터리 방전(전력 0):** 진짜 방전. 복구 불가 → **암전 → 연호 강제 점프스케어 → 사망**(FNAF1식). 자원 관리 실패의 죽음.

- **현우 배선 고장(≠방전):** 현우 3스택이 **배선을 끊어** 전기 고장 → **창고런 통로 열림 → 전기실 브레이커 리셋로 복구.** 수리 가능한 위기. (= 우리가 “정전”이라 부르던 것)

- 두 사건은 별개: 방전=게임오버 / 배선고장=대응 가능 위기. **배선 고장은 매일 밤 최대 1회.**

- 현우 셔터 실패 시 처벌은 날짜별로 점증: **2일차=배터리 깎임 / 3일차~=스택→배선 고장.**

### ② 오디오 / 종소리 (프레디3 레퍼런스)

- 재생 시 **종소리**가 울려 귀신을 **제자리로 유도.** **연호 전용 대응**(현승은 응시로 분리).

- **광역**(복도/방, 환풍구 안 안 닿음) · **거리별 후퇴**(창문앞 강 / 먼곳 약, 연호만 창문앞도 2~3칸).

- **무시 확률 1/7**(원작) — 단 **창문 앞에선 무시 없음**(운사 방지).

- **쿨 5.4초 · 전력 소모 · CCTV 패널 안.** 연호는 CCTV로 추적하며 종(보면서 침).

- **밤당 횟수 제한**(2일 5/3일 4/4일 3/5일 2) → **초과 시 오디오 고장.**

- **오디오 고장 = 통합 상태:** 종 횟수 초과 / 현승 피격 둘 다 같은 “오디오 다운” → 리셋 필요, 그동안 종 못 침(연호 무방비).

### ③ 산소순환장치 (환기) — enabler, 직접 사망 X

- 김욱(카메라 노출 초과) 또는 준영(관리실 방치)에게 당하면 → **환기 오류 ON.**

- **환기 오류 = 죽이지 않음.** 특정 시간 후 **화면이 흐려졌다 돌아옴(강제 화면 전환)** → 안 고치면 **주기적 반복** → 매 전환마다 armed 귀신(연호·현승)에게 공격 기회.

- **on/off 하나**(김욱·준영 누가 유발하든 동일, 중첩 없음). **리셋 5초**로 복구.

- 즉 환기 오류는 “빈틈을 강제로 여는” enabler. 직접 살해는 연호·현승이 함.

### ③-b 리셋 시간 (확정)

- **환기 리셋: 5초 / 오디오 리셋: 5초 / 둘 다 동시: 8초**(따로 10초보다 빠름).

- 리셋 중엔 다른 방어 불가 → 둘 다 고장 시 8초 묶임(연호 급습 위험).

### ④ 창문 / 환풍구 셔터 (관리실 방어)

- **창문 = 정보 도구.** 닫는 문 없음 → 복도 엿보고 대응. (FNAF3식)

- **종 = 복도/방 접근 대응 / 셔터 = 환풍구 접근 대응.** 환풍구엔 종 안 닿음.

- **환풍구 점유 잠금:** 한 번에 한 마리만(현우 우선, 막히면 현승은 복도로).

- ❌ **FNAF1식 여닫이 문 탈락:** 연호=종 정체성 보호.

### ⑤ 브레이커 수리 (SL Breaker Room식) — 창고런

- 배선 고장(현우 3스택) 시 통로 열림 → **창고[윤진] → 전기실[윤석] → 탈출**의 5박자 시퀀스.

- **브레이커 3개**(공부방 / 로비·화장실 / 관리실 전원) 복구 → 정전 해제.

- **freeze 3단계:** 통로 진입~수리완료=완전정지 / 탈출중=저속 / 복귀 후=정상.

- 윤진(청각 회피)·윤석(스파크·달래기) 둘 다 거스르면 **즉사.** (companion §4.5/5/6)

## 6. 귀신 도감 (7마리)

### 아현승 — 1일차~ (팬텀 프레디 + 퍼펫 통합, 4단계)

- **거점:** 공부방1 (랜덤 출현, 평소 정적)

- **루트(복도 경유 기본 + 가끔 환풍구):**

- R1(짧음): 공부방1 → 복도 → 화장실 → 창문

- R2(중간): 공부방1 → 공부방2 → 복도 → 화장실 → 창문

- R3(환풍구 변칙): 공부방1 → 공부방2 → [환풍구] → 화장실 → [환풍구] 관리실 측면

- **4단계 메커니즘(종 아님 — 응시 대응):**

- **접근:** CCTV로 점점 다가옴 (복도면 추적 가능, 환풍구 변칙이면 갑자기 측면)

- **경고(팬텀):** 창문에 **절뚝이며 가로질러 지나감** → CCTV 내린 채 **계속 응시하면** 희미해지며 사라짐(워크패스 길이 = 대응 시간). 시선 돌리거나 패널 올리면 **리셋**

- **1차(팬텀, armed):** 다 지나갈 때까지 응시 실패 → armed → **다음 화면 전환 시 점프스케어** → **오디오 고장**(즉사 아님)

- **2차(퍼펫 즉사):** 오디오 고장 상태로 리셋 실패 → 즉사

- **종과 무관**(응시 전용). 환풍구(R3)로 오면 셔터로 막음. STRIKE1 시 짧은 잠금 + 연호 틈타기.

### 조현우 — 2일차~ (3스택 정전)

- **거점:** 공부방2 (랜덤 출현) — **환풍구 전용 진입.** 이동 중 복도/방 카메라를 길게 경유해 존재감↑(종 독점 해제로 환풍구 전용 복귀).

- **루트(방·카메라 경유 + 환풍구 진입):**

- R1: 공부방2 → [환풍구] → 화장실 → [환풍구] → 관리실

- R2: 공부방2 → 복도 → 로비 → 복도 → 화장실 → [환풍구] → 관리실

- R3: 공부방2 → 복도 → 화장실 → [환풍구] → 관리실

- → **“환풍구로만 들어오는 귀신”** (최종 진입만 환풍구 셔터로 대응, 종 무관)

- **대응:** **환풍구 셔터** 차단. 멀리=CCTV 환풍구 카메라 / 코앞=불빛 버튼으로 확인 → 셔터(쾅쾅 소리 + 복귀). 못 막으면 armed → 화면 전환 시 점프스케어 → 스택+1. (companion §4.3b)

- **3스택 시스템:** 빈도 ↑. 한 번 뚫려도 즉시 정전 아님 → **누적 3회.**

- **후폭풍 점증:** 1스택 조명 깜빡임+시야 흐림(노랑) → 2스택 CCTV 노이즈(주황) → 3스택 **배선 고장(정전)**

- **스택 리셋:** 매일 밤 0 · 정전 1회 후 그날 추가 정전 없음

- **날짜별:** 2일차=셔터 실패 시 배터리 깎임(스택 없음) / 3일차~=스택→배선 고장(정전).

- **역할:** 배선 고장 → 창고런 강제. 빈도 높아도 3스택+매일 리셋으로 남발 방지.

### 장윤석 — 4일차~ (전기실 / SL Breaker Room)

- **거점:** 전기실 전용(CCTV 사각). 창고런 2단계(윤진 통과 후).

- **메커니즘:** 두 화면(패널: 브레이커 3개 RESTART+위험도 / 전경: 어두움, **스파크 때만 윤석 실루엣**). 전기 올리면 위험도↑ + 윤석 4단계 접근 / 패널 내림·**달래기(스페이스)**로 위험도↓.

- **브레이커 3개:** 공부방 / 로비·화장실 / 관리실 전원.

- **당하면:** **즉사**(위험도 최대 + 최종 단계에서 모니터 내릴 때). 최소시간 보장(운사 X). (companion §6)

### 조윤진 — 3일차~ (창고 / SL Ballora Gallery)

- **거점:** 창고 전용(CCTV 소리만). 창고런 1·3단계(들어가기/탈출).

- **메커니즘:** 어두운 창고를 **연속형 전진 홀드**(누르면 기어가고 떼면 멈춤). 스테레오 소리로 윤진 위치 파악 → 가까울 때 전진 = 즉발 발각.

- **당하면:** **즉사**(소리 큰데 전진한 자기 입력 = 공정). 게이지 없음. (companion §5)

### 노연호 — 2일차(맛보기) → 3일차(약)~ → 5일 풀가동 ★메인 빌런 (스프링트랩 포지션)

- **거점:** 공부방2, **가장 자주 이동.** 환풍구 사용 불가(몸집) → 항상 복도/문으로만, 창문 수렴.

- **루트(전부 창문 수렴):**

- L1(정면/로비): 공부방2 → 복도 → 로비 → 복도 → 관리실 창문

- L2(공부방1 경유): 공부방2 → 공부방1 → 복도 → 화장실 → 관리실 창문

- L3(화장실 잠복): 공부방2 → 복도 → 화장실 →(잠복)→ 관리실 창문

- → 다양성은 루트보다 **행동 엔진**(흉포 토글·행동 굴림, companion §2)에서.

- **대응:** **종**(연호 전용). 무시 1/7(창문 앞 무시 없음) · 거리별 후퇴 · 쿨 5.4s · 밤당 횟수 제한. CCTV로 추적하며 종.

- **당하면:** **즉사** — ①창문 앞 armed + 화면 전환 ②배터리 방전 암전(FNAF1식).

- **설계 의도:** 2일차 맛보기 1회(사망 가능) → 3일차 정식(약) → 5일 최종(AI 16). 창고런에 안 잠긴 직접 경비 위협의 주력.

### 김욱 — 3일차~ (벌룬보이 / 팬텀 BB)

- **거점:** CCTV에 **랜덤 출현** (7대 중 한 곳, 노이즈 신호로 표시)

- **대응:** 잡힌 카메라에 떠 있을 때 → **시간 내에 카메라를 끄거나 다른 데로 돌려야** 안전. (계속 보면 안 됨)

- **실수 시:** 큐된 카메라를 **노출 시간 이상 계속 보면** → 갑툭튀 + **환기 오류 ON.**

- **당하면(환기 오류):** 화면 흐려짐 주기 반복 → 매번 armed 귀신 공격 기회. **리셋으로 복구**(직접 사망 X).

- **역할:** 직접 살해 X. **빈틈을 강제로 만드는 enabler.**

### 준영 — 3일차~ (팬텀 포시) ※7번째 귀신

- **출현:** AI 없음. 그날 출현 여부만 확률(3일 낮게 → 5일 1/10).

- **작동:** **관리실 구석에 나타남** → 카메라 켜면 사라짐 → **또 나옴**(점프스케어 당할 때까지 반복).

- **하루 1회 = 점프스케어 1회.** 한 대 맞으면 그날 퇴장. 그 전까진 계속 깐족.

- **김욱과 정반대:** 김욱=카메라에서 벗어나야 / 준영=카메라를 켜야.

- **결과:** 교란형(즉사 아님) — **환기 오류 ON**(김욱과 동일 결과, 유발 경로만 다름).

## 7. 일차별 시퀀스

### 공통 골격 (모든 밤)

- **밤 길이:** 6분 30초, 12시→6시 (1일차만 ~4분, 빠르게)

- **밤 리듬:** 12~2시 워밍업 / 2~4시 본격화 / 4~5시 흉포 시작 / **5~6시 클라이맥스(순수 경비)**

- **5시 이후:** **창고런(정전) 안 생김 · 현우 퇴장** → 연호(흉포) 주역 + 현승·김욱·준영. 윤진·윤석 자동 부재.

- **창고런 시간:** 밤 시계 **정지** → 복귀 시 **30초 점프**. (6시 겹침은 5시 컷오프로 차단)

설계 원칙: **매일 새 시스템 1개씩, 안전한 환경에서 먼저 학습 → 다음 날 위험과 결합.** 특히 3일차에 “정전→창고런”을 **윤석 없이** 먼저 체험시켜 학습 곡선을 분산한다.

### 1일차 — “첫 야간” (튜토리얼, 죽음 없음, ~4분)

- **활성:** 현승 단독 (AI 3, 느림)

- **학습:** CCTV 보기 · 시야 4구역 전환 · **현승 창문 응시** (종/셔터는 쓸 일 없음 → 2일차)

- **시퀀스:** 12시 CCTV 첫 작동 시 **포스트잇**(종·환기·CCTV 안내) → 12~1시 정적 → 1~3시 현승 활성(복도 이동) → 3~4시 **현승 1회 확정 출현 → 창문 워크패스 → 응시 학습**(실패해도 죽음 없음) → 4~6시 잔잔.

- **톤:** 으스스하지만 안전. “꿀알바네.”

### 2일차 — “셔터와 종” (전력 관리 학습, 죽음 가능)

- **활성:** 현승(응시) + **현우**(셔터) + **연호 맛보기(확정 1회)**

- **학습:** **환풍구 셔터**(현우) · **종**(연호 맛보기) · **전력 관리**

- **시퀀스:** 12~2시 현승 + **현우 첫 등장 → 셔터 학습** → 2~4시 현우 빈도↑ → 4~5시 **연호 맛보기 확정 1회 → 창문 접근 → 종 첫 학습**(클라이맥스) → 5시 현우 퇴장 → 5~6시 마무리.

- **현우 처벌:** 셔터 실패 = **배터리 뭉텅 깎임**(스택/배선고장 없음 — 3일차로). 종·CCTV 남발과 겹쳐 전력 빠듯.

- **죽음:** ①연호 맛보기 = 즉사 가능 ②**배터리 방전 → 암전 → 연호 점프스케어**(FNAF1식). “자원 관리 못 하면 죽는다” 각인.

### 3일차 — “정전과 창고” (창고런 첫 학습, 빡셈)

- **활성:** 현승·현우 + **김욱·준영·윤진·연호(정식 AI 5).** 종 4회.

- **신규 학습:** 김욱(카메라 벗어나기) · 준영(카메라 켜기) · **첫 창고런**(윤진)

- **타임라인:** 12~1시 김욱 첫 등장 → 1~3시 현우 스택 + 준영 가능(확률 낮음, 점프스케어까지 반복) → **~3:30 정전**(현우 3스택이면 그걸로, 아니면 3:30 강제 1회) → **첫 창고런**(윤진, **통로 위 메모로 안내**, 윤석 없음) → 4~5시 연호 정식+흉포 시작 → 5시 현우 퇴장·창고런 컷오프 → 5~6시 클라이맥스.

- **빡셈:** 첫 창고런이지만 윤진 관대하게 안 함(죽으며 배움). 윤석만 없음.

### 4일차 — “창고의 주인” (창고런 풀세트, 빡셈)

- **활성:** 전원 + **윤석(첫 등장).** 종 **3회.**

- **신규 학습:** 윤석(스파크·4단계·달래기) — **안 봐줌**(3일차 윤진와 일관)

- **현우 확률 상당히↑**(강제 정전 대신 — 운엔 맡기되 사실상 자주 정전)

- **창고런 풀세트:** 윤진 → **윤석** → 윤진 탈출. 둘 다 즉사 → 진짜 위험.

- **연호:** AI 9, 흉포 자주. 종 3회라 아껴 써야 함.

- **타임라인:** 12~3시 일상(연호 적극) → 정전 시 풀세트 창고런 → 4~5시 흉포 빈번 → 5시 현우 퇴장 → 5~6시 클라이맥스.

### 5일차 — “마지막 밤” (전원 풀가동 + 엔딩)

- **활성:** 전원. 종 **2회.** 연호 AI 16(흉포 거의 상시).

- **신규 학습:** 없음 (종합). 모든 위협 최대치.

- **난이도:** 어렵지만 **공정하게 클리어 가능**(운사 아님 — 완벽 플레이 시 생존). 정확한 값은 프로토타입 튜닝.

- **타임라인:** 12시부터 빡셈 → 정전 시 창고런 최고난도 → 4~5시 전 위협 동시 → 5시 현우 퇴장 → 5~6시 최종 클라이맥스(종 고갈) → **6시 생존.**

- **엔딩:** 6시 생존 → **공사 시작 → 친구들 해방.** 톤=담담한 헌정. **구체 연출은 보류**(게임 분위기 나온 뒤 결정 — 작업 최소 원칙).

## 9. 연쇄 붕괴 (게임의 핵심 재미)

자원을 전력 하나로 묶고, 사고가 사고를 부르게 설계한다.

- **현승에게 당함** → 오디오 고장 → **연호를 못 막음**(즉사 위험 급등) + 연호 흉포 토글

- **현우에게 당함** → 3스택 배선 고장 → **창고런 강제**(독립 시퀀스) → 윤진(즉사)+윤석(즉사) 회피 + 연호 흉포

- **김욱에게 당함** → 환기 오류 → 화면 흐려짐 주기 반복 → 매번 armed 귀신 공격 기회 + 연호 흉포

- **준영에게 당함** → 환기 오류(김욱과 동일) — 직접 살해 X, 빈틈 강제

핵심 축: **현우(3스택) → 배선 고장 → 창고런(윤진+윤석)** 이 4일차 이후 난이도의 등뼈. **연호 흉포 토글**이 캐스케이드 엔진 — 위 사고들이 연호를 흉포하게 만들어 연쇄 가속(companion §2.5). 창고런 중엔 다른 귀신 정지(freeze) → 위협은 “관리실 함락”이 아니라 **창고런 즉사 회피**에 집중.

## 10. 서사 (분위기 레이어 — 작업 최소 원칙)

**원칙:** 서사는 게임플레이 위에 얹는 *양념*이지 메인이 아니다. 플레이어가 안 봐도 게임은 굴러간다. 수집품·로어 추적 같은 별도 시스템은 만들지 않는다. 서사 욕심으로 작업을 늘리지 말 것.

**톤:** 애정 어린 헌정. 공포보다 연민. 귀신=입시에 갈려나간 학생들(제작자의 실제 친구들, 동의받음). 플레이어는 걔네를 *물리치는* 게 아니라 하룻밤을 *버티며 지켜본다.*

**셋업:** 화재로 폐업한 독서실. 새 가게 공사 전 **일주일간** 야간 경비 알바 모집 → 주인공(평범한 알바)이 높은 일당만 보고 들어온다. (5일 영업 = 공사 전 기간이라는 자연스러운 핑계)

**진실의 층위(능동적 해독 불필요, 눈에 들어오면 느끼는 수준):** - 표면(1일): 그냥 불나서 망한 독서실. 꿀알바. - 균열(2~3일): 얘네 학생 같은데 왜 안 가지? - 진실(4~5일): 화재 때 못 빠져나간 학생들. “이것만 풀고… 조금만 더…” 하다가. (입시 은유 — 은근하게)

**전달 방식 (추가 작업 ≈ 0, “어차피 만들 것”에 얹기):** - CCTV 속 환경 디테일: 책상 낙서(“D-100”, “잠 좀 자고싶다”), 그을린 벽, 책상 하나에 놓인 꽃 한 송이 → **텍스처에만** 넣음, 별도 시스템 X - 첫날 주인 문자 1통: 튜토리얼 + 톤 세팅 (“CCTV랑 환기만 신경 써요, 가끔 소리나도 신경쓰지 마세요”) - 귀신 외형 자체가 서사: 친구 스캔 모델 + 교복/독서실 분위기 → 말 없이 “학생이었음” 전달

**엔딩:** 5일째 새벽, 경비 종료 → **공사 시작 = 공간 소멸 = 친구들 해방(보내줌).** 주인공은 영문 모른 채 일당 받고 나오지만, 플레이어는 무슨 일이 있었는지 안다. 짧은 아웃트로 1장면. 담담해서 더 슬픔.

6명 개별 뒷이야기는 문서화하지 않음. 친구별 모델링 시 “얘는 이런 분위기” 정도로 자연스럽게 녹임. 메커니즘은 이미 확정됨.

# 0. 공통 AI 엔진 (전 귀신 공유)

FNAF3 디컴파일 로직 기반. 모든 귀신은 아래 **2개 엔진** 중 하나를 쓰고, 차이는 **파라미터**로만 준다. 밸런싱 시 엔진 한 곳만 고치면 전체 적용. 공통 입력: **AI 레벨 = 8장 날짜별 곡선값.** 모든 시간은 초 단위로 재튜닝(레딧 프레임값 직역 금지).

## 엔진 A — 능동 빌런 (연호 전용)

매초 루프: move_counter += (평소 1 / 흉포 2) → 5개 임계값 전부 초과 시 행동 준비 → 굴림(평소 1~3 / 흉포 1~4) → 1=멈춤(+total_turns) · 2=후퇴 · 3=전진 · 4=급습(흉포만) → 이동 시 total_turns=0. - **흉포(aggressive) 토글:** 상황이 귀신을 흉포하게(연쇄 붕괴 엔진). 상세 §2.5. - **total_turns 보정:** 실패 누적 → 다음 행동 가속(운빨 보정). - 상세: §2.

## 엔진 B — 큐 기반 팬텀 (현승·현우·김욱 공유)

매 CYCLE(기본 20s)마다:
  if (대상 카메라를 안 보는 중) and (rand(0~9) < AI레벨):   # "AI in 10"
      해당 귀신을 특정 위치에 '큐(queue)'
  큐된 귀신이 화면에 노출되고:
      노출 시간 >= EXPOSURE_LIMIT (일별 단축) → "공격 예약(armed)"
  카메라를 안 보면 일부 귀신은 비활성/해제(귀신별 규칙)
강제 스폰: 지정 시각(또는 다음 조건 충족 시) 무조건 1회 큐

# 0.5 점프스케어 공통 원리 (전 귀신) — “화면 전환 시 발동”

FNAF 근본 원리. 귀신이 **armed(공격 확정)** 상태가 되면, **다음 화면 전환 순간**에 점프스케어. 적의 “다가오는 애니” 불필요 — 화면 한 번 깜빡일 때 “짠” 등장.

## 화면 전환 트리거 (armed 상태에서 이 중 하나라도 일어나면 발동)

- CCTV 올렸다 내릴 때

- 리셋 패널(환기/오디오) 올렸다 내릴 때

- 시야를 다른 구역으로 돌려 대상이 시야에서 사라질 때 (좌/우/후면 회전)

- **후면(창고 통로) 볼 때** — armed면 강제로 정면 복귀하며 점프스케어

- **환기 오류 → (유예 후) 화면 흐려졌다 돌아오는 강제 전환, 안 고치면 주기 반복** — 가만히 있어도 결국 당함(도망 봉쇄)

⚠️ 환기 오류는 **유예 시간** 후 전환(리셋 패널로 고칠 기회). 안 고치면 주기적으로 계속 전환.

## 귀신별 armed 조건

| 귀신 | armed | 결과 |
| --- | --- | --- |
| 연호 | 창문 앞 실루엣 + 종 못 침 | 즉사 |
| 현승 | 창문 워크패스 응시 실패 | 오디오 고장(1차) |
| 김욱 | 카메라 노출 한계 초과 | 환기 오류 |
| 준영 | 관리실 등장 후 시간 초과 | 환기 오류 |
| 현우 | 환풍구 진입(셔터 실패) | 스택+1(점프스케어 동반) |

가만히 armed 대상만 보고 있으면 당장은 안 당하지만 그동안 아무것도 못 함(압박). 환기 오류(5번)만 강제(주기 반복)라 회피 불가.

## 우선순위 / 중복

- **즉사 ****>**** 비즉사.** 즉사: 연호 > 현승퍼펫(창고런 윤진·윤석은 freeze라 제외).

- **비즉사 공통 패턴(FNAF3 팬텀 잔상식):** 점프스케어 = **팬텀 얼굴 잔상(1~2초) 화면에 뜸 + 그동안 모든 조작 불가(카메라·패널·셔터·종 먹통) + 해당 효과 적용.**

- 현승: 잔상 + 오디오 고장 / 김욱·준영: 잔상 + 환기 오류 / 현우: 잔상 + 스택+1

- **잔상 시간 = “짧은 무적”**(이 동안 다음 점프스케어 안 뜸) → 비즉사 여러 개면 잔상 순차(현승 > 김욱 ≈ 현우 > 준영). **준영만 하룻밤 1회**, 나머지 반복.

- **연호 틈타기:** 잔상 끝나 화면 돌아오는 순간 = 화면 전환 → armed 연호 있으면 그때 덮침(별도 규칙 없이 §0.5로 자동).

# 1. 아현승 (튜토리얼 / 팬텀 + 퍼펫)

## 1.1 개요

- **거점:** 공부방1 (CAM 01)

- **성격:** 상시 위협. 1일차부터 활성. 모든 후속 귀신 설계의 기준 틀.

- **대응 수단:** **창문 응시**(종 아님 — 종은 연호 전용) + 오디오 리셋(퍼펫 방지)

- **결과:** 1차 = 오디오 고장(비치명) → 방치 시 2차 = 즉사

- **종 무관:** 현승은 종소리에 영향받지 않음. 복도 접근이어도 응시로만 대응(환풍구 R3는 셔터).

## 1.3 경로 노드 (CCTV 가시성 포함)

화장실은 카메라 없음(사각) + 환풍구 교차점 → 항상 마지막 블라인드 노드. 그 직후 창문(또는 환풍구 측면) 등장. 모든 방은 복도 허브로 연결(공부방1↔공부방2만 직접). 현승은 복도 기본, 가끔 환풍구.

- **R1 (짧음/급습):** 공부방1 [CAM01] → 복도 [CAM] → 화장실 [사각] → 창문

- **R2 (중간):** 공부방1 [CAM01] → 공부방2 [CAM02] → 복도 [CAM] → 화장실 [사각] → 창문

- **R3 (환풍구 변칙):** 공부방1 [CAM01] → 공부방2 [CAM02] → [환풍구] → 화장실 [사각] → [환풍구] → 관리실 측면

활성화 시 R1~R3 중 랜덤. R3는 가끔만(복도캠 건너뛰는 변칙 → 단조로움 해소). 환풍구는 몸집 작은 귀신 공용(연호 제외).

# 2. 노연호 (메인 빌런 / 스프링트랩 엔진)

FNAF3 스프링트랩 디컴파일 로직을 기반으로 우리 게임에 맞게 재구성. 연호의 모든 공포는 **“흉포 토글 + 행동 굴림 + 실패 보정”** 하나의 엔진에서 자동으로 흘러나온다. 5종 패턴은 별도 스크립트가 아니라 이 엔진의 출력이다.

## 2.1 개요

- **거점:** 공부방2. 가장 자주 이동. 환풍구 사용 불가(몸집) → 항상 복도/문으로만.

- **등장:** 2일차(맛보기 1회) → 3일차(약) → 5일(풀). AI 레벨 = 8장 곡선(2/5/9/16…).

- **대응:** 종(되돌림) — 단, **종 무시 확률** 존재. 무시당해도 즉사 아님(아래).

- **당하면:** **즉사** (후폭풍 없음, 유일).

- **정공법 빌런:** 항상 정면 창문으로 수렴(현우=환풍구 측면과 대비).

## 2.2 루트 (전부 창문 수렴, 맵 인접 준수)

- **L1 (정면/로비):** 공부방2 → 복도 → 로비 → 복도 → 관리실 창문

- **L2 (공부방1 경유):** 공부방2 → 공부방1 → 복도 → 화장실 → 관리실 창문

- **L3 (화장실 잠복):** 공부방2 → 복도 → 화장실 → (잠복) → 관리실 창문 > 루트는 분기 시작용일 뿐, 진짜 다양성은 §2.4 행동 엔진에서 나온다. “창고 사라짐”은 L3 화장실 잠복으로 대체.

## 2.3 핵심 엔진 — 이동 판정 (스프링트랩식)

매초 진행되는 루프: 1. **move_counter** += (평소 1 / 흉포 2) per second 2. 매초 move_counter를 **5개 임계값과 비교** → 전부 초과 시 “행동 준비됨” 3. 준비되면 **행동 굴림:** - 평소(aggressive=0): 1~3 중 랜덤 - 흉포(aggressive=1): 1~4 중 랜덤 4. 굴림 결과: - **1 = 실패(멈춤)** → 그 자리 유지 + total_turns += 1 - **2 = 후퇴** → 이전 노드로 (멀어짐) - **3 = 전진** → 다음 노드로 (다가옴) - **4 = 급습(흉포 전용)** → 여러 노드 빠르게 주파 / 페이크 5. 실제 이동(2·3·4) 시 total_turns = 0

**total_turns 보정:** 실패(1)가 누적될수록 다음 “준비”가 빨라짐(임계값 더 빨리 넘김). → 운으로 영원히 안 옴/연속 순삭 방지. 공정성 자동 확보.

## 2.4 5종 패턴 = 엔진 출력 매핑

| 패턴 | 엔진에서 발생 | 잠금 해제 |
| --- | --- | --- |
| ① 멈춤 | 굴림=1 | 2일~ |
| ② 종 무시 | 종 입력 시 확률 판정(아래) | 2일~ (핵심 각인) |
| ③ 페이크 | 굴림=4 중 “창문 근접 후 2(후퇴)” 연계 | 4일~ |
| ④ 화장실 잠복 | L3 진입 + 굴림=1 연속 | 3일~ |
| ⑤ 급가속 | 굴림=4 (흉포 전용) | 5일~ (흉포 빈발) |

날짜 잠금은 “흉포 발동 빈도 + AI 레벨”로 자연 구현됨(4는 흉포에서만 나오므로 후반에 잦아짐).

## 2.5 흉포(aggressive) 토글 — 연쇄 붕괴의 엔진

**aggressive = 0/1.** 매 15초 0으로 리셋되지만, 조건 충족 시 즉시 다시 1. 2일차(맛보기) 밤 시작엔 항상 0. **흉포로 만드는 조건 (우리 연쇄 붕괴와 직결):** - **현승에게 당함**(오디오 고장/팬텀 스트라이크) → 흉포 - **김욱/준영에게 당함**(환기 오류) → 흉포 - **정전 발생**(현우 3스택 등) → 흉포 (단, 창고 통로 진입 시 freeze로 정지) - **새벽 4~5시** → 흉포 - **관리실에 10초+ 가만히**(아무 조작 없음) → 흉포 (방심 처벌) - **확률:** 매 15초 rand(0~4) < AI레벨 이면 흉포 (후반 날일수록 자주)

**효과 (이동에만 영향, 종 무관):** - move_counter 증가 **2배**(평소 1 → 흉포 2/초) → 더 빨리 움직임 - 행동 굴림에 **4(급습/페이크) 추가**(평소 1~3 → 흉포 1~4) → 평소 얌전하다 표변 - **종 무시 확률은 1/7 고정**(흉포여도 안 바뀜). 흉포의 위협은 순수 “빨리·갑자기 다가옴” → 종을 더 자주 쓰게 만들어 **횟수 제한 압박**으로 연결. - “현승/김욱한테 당하면 연호가 미쳐 날뛴다”는 캐스케이드가 이 토글로 구현.

## 2.6 종 (원작 FNAF3 오디오 유인 방식)

- 종 침 → **무시 확률 1/7**(원작). 무시당하면 안 먹힘 → **다시 쳐야 함**(횟수·전력 낭비).

- **단, 창문 앞(armed)에선 무시 없음** → 최후의 순간엔 종 100% 통함(문 없는 게임이라 운사 방지).

- 먹히면 **거리별 후퇴**(§2.6b).

- **쿨타임 5.4초**(원작 6초 근사) · **전력 소모** · **CCTV 패널 안**.

- **밤당 사용 횟수 제한:** 2일 5회 / 3일 4회 / 4일 3회 / 5일 2회. **초과 시 오디오 고장**(=현승 피격과 동일 상태, 리셋 필요 → 종 못 침).

- **광역**(복도/방, 환풍구 안 안 닿음). 연호는 뚱뚱해 환풍구 미사용 → 벤트 제외 규칙 무의미.

- 난이도 = 횟수 제한 + 후반 종 부족으로 조절(면역 시스템 폐기).

## 2.6b 거리별 후퇴

| 연호 위치 | 후퇴량 |
| --- | --- |
| 창문 앞 | 면역 해제 + 2~3칸(처음으론 안 감) |
| 중간 | 1~2칸 |
| 먼 곳 | 1칸 |

연호는 창문 앞에서도 처음으로 안 감(빌런 특권). 일반 귀신(현승 등)은 창문앞=처음으로지만, 연호는 끈질김.

## 2.6c 대응 손맛 (CCTV-종 충돌 해결)

- 연호 정석 대응 = **CCTV(올림)로 추적하며 종으로 미리 끊기.** 종이 CCTV 안 → **보면서 친다**(충돌 없음).

- 현승(CCTV 내리고 응시)과 **정반대 손놀림** → 둘이 구분됨.

- 창문 앞 도달 = “놓친 상황” → 면역 해제 + 급히 CCTV 올려 종(최후 기회).

## 2.6d 사망 조건

- **연호 armed = 창문 앞 실루엣 등장.** 이 상태에서 **화면 전환이 일어나면 점프스케어 → 즉사.**

- 창문 앞에선 **면역 해제** → 종 항상 통함 → 죽음은 “제한시간 내 종 못 친” 반응 실패일 때만(공정).

- **배터리 방전(전력 0):** armed 무관 — **암전 = 강제 화면 전환** → 연호 강제 점프스케어 → 사망(FNAF1식 자원 실패사).

- 화면 전환 트리거는 §0.5 공통 원리 참조.

## 2.7 카메라 강제 다운 (숨기 봉쇄)

- 현승 함정(“카메라 내리면 죽음”) 회피로 **카메라를 계속 켜두는 플레이** 차단용.

- **연호가 창문 근접(마지막 노드 도달)** 하면 → **CCTV 패널 강제 다운** → 숨어있던 현승 함정 발동 가능 + 연호 본인 대응 강제.

- 즉 “카메라에 숨기”는 단기만 가능, 연호가 오면 강제로 끌려 나옴.

# 3. 김욱 (벌룬보이 / 엔진 B — 큐 기반 팬텀)

# 4. 조현우 (환풍구 / 엔진 B + 3스택 정전)

이동(복도/방)은 자유, **관리실 진입만 환풍구 큐(엔진 B).** 빈도는 높지만 3스택 덕에 정전(창고런)은 남발 안 됨.

## 4.1 개요

- **등장:** 2일차~. “환풍구로만 들어오는 귀신.”

- **대응:** 환풍구 큐 노출 시 **셔터 차단.**

- **누적 결과:** 셔터로 못 막고 진입당함 = 1스택. **3스택 → 정전.**

- **리셋:** 매일 밤 0. 정전 1회 후 그날 추가 정전 없음.

## 4.2 루트 (방 경유 + 환풍구 진입)

- R1: 공부방2 → [환풍구] → 화장실 → [환풍구] → 관리실

- R2: 공부방2 → 복도 → 로비 → 복도 → 화장실 → [환풍구] → 관리실

- R3: 공부방2 → 복도 → 화장실 → [환풍구] → 관리실 > 이동 구간은 복도/방, 최종 진입만 환풍구 셔터로 대응(현우 정체성).

## 4.3 엔진 B 파라미터

- **CYCLE:** 20s

- **큐 확률:** rand(0~9) < AI레벨 (2일 낮음 → 5일 높음)

- **대상:** 환풍구 CAM (관리실 진입부)

- **노출 결과:** 큐된 채 셔터 안 닫으면 진입 → **스택 +1**

- **비활성:** 셔터 차단 성공 시 후퇴, 다음 CYCLE 재시도

## 4.3b 대응 흐름 (FNAF2 환풍구식, 이중 구조)

- **멀리서:** CCTV로 **환풍구 전용 카메라** 감시 → 현우 환풍구 진입 확인.

- **코앞:** 현우가 관리실 도착 → 오른쪽 시야(환풍구)에서 **불빛 버튼**(FNAF1식 문조명) 눌러야 현우 보임(평소 어두움).

- **시간 내 셔터 닫으면** → **셔터 쾅쾅 두드리는 소리** + 현우 **처음 장소로 복귀**.

- **시간 내 못 막으면 → armed** → 화면 전환 시 **점프스케어 → 스택 +1**(비즉사, §0.5).

- 셔터 유예 시간: 후반 날일수록 짧아짐(수치 프로토타입).

- 손 바쁨: “CCTV 감시 → 오른쪽 봄 → 불빛 → 셔터” 다단계 = 현우 까다로움(의도).

## 4.4 3스택 시스템 (후폭풍 점증)

| 스택 | 후폭풍 | 경고등 |
| --- | --- | --- |

| 2 | CCTV 노이즈/지직(감시 방해) | 주황 |
| 3 | **정전** → 창고런 강제 | 정전 |

# 4.5 창고런 시퀀스 (윤진 + 윤석 통합 무대)

정전 시 발동. 본체=경비를 너무 끊지 않게 압축하되 **밀도 높게**(총 약 2~2.5분). “짧으면 의미 없다”를 5박자 + freeze 3단계로 해결. 원작 압축 원칙 = 메커니즘 유지 + 반복 횟수만 단축(윤진 연속형 통로 / 윤석 브레이커 3개).

## 구조 (5박자)

[결정] 정전 발생 → 귀신들 아직 활동 → "지금 나갈까?"
  ↓ 통로 진입 (freeze 시작)
[1막] 창고 기어가기 (윤진 청각, 들어가는 길)
[2막] 전기실 수리 (윤석 달래기, 브레이커 2~3개)
  ↓ 수리 완료 = 전력 복구 = freeze 해제(저속 모드로)
[3막] 창고 다시 기어나오기 (윤진 + 시간압박, 탈출 = 클라이맥스)
  ↓
[복귀] 관리실 — 귀신 정상화, 즉시 경비 재개

들어갈 땐 freeze라 안전, 나올 땐 시간 흐름 → 같은 윤진 창고가 정반대 긴장. 공들인 윤진을 **두 번** 사용(존재감↑).

## freeze 3단계

| 구간 | 다른 귀신 상태 |
| --- | --- |
| 통로 진입 ~ 수리 완료 | **완전 freeze(정지)** |
| 수리 완료 ~ 관리실 복귀(3막 탈출) | **저속 모드**(AI 레벨 down, 평소보다 훨씬 느림) |
| 관리실 복귀 후 | 정상 복귀 |

저속 모드 = 탈출에 “빨리 나가야” 압박은 주되, 풀스피드 흉포 연호 즉사하는 불공평 방지.

- “결정” 구간 길이(정전~통로진입 가능 시간)

# 5. 조윤진 (창고 청각 스텔스 / SL Ballora Gallery 원본)

창고런 전용. 엔진 A/B 안 씀 — **플레이어 능동 입력(기어가기)에 반응하는 즉발식.** SL 원본 Ballora Gallery에 충실.

## 5.1 개요

- **등장:** 3일차~. 정전 시 창고런에서만 조우.

- **무대:** 어두운 창고. 플레이어가 **엎드려 한 칸씩 전진**(입력식)으로 통과. 시각 거의 없음, 청각 전부.

- **윤진:** 어둠 속에서 음악/소리 내며 통로를 오감 → **스테레오로 거리·방향** 들림.

- **당하면:** **즉사**(즉발식).

## 5.2 핵심 메커니즘 (즉발식 타이밍 게임 — 연속형)

- 이동 = **전진 입력 홀드**(SL 원본 방식). 누르면 누르는 대로 계속 전진, 떼면 멈춤. “전진 중 / 멈춤” 둘 중 하나.

- **소리 작음(윤진 멀다):** 전진 안전.

- **소리 큼(윤진 가깝다):** 전진하면 **즉시 발각 → 점프스케어 → 즉사.** → 떼고 멈춰야 함.

- **게이지 없음.** 가까울 때 전진한 그 순간 잡힘.

- 공정성: 가만히 있으면 안 죽음. 죽음은 “소리 큰데 굳이 전진 홀드한” 명백한 자기 입력.

## 5.3 위키 차용 (UCN/SL 혼합 → 우리식)

- **발각 민감도 = AI레벨/N (UCN x/41 변형):** 후반 날일수록 더 먼 거리/작은 움직임도 발각. 8장 곡선(3일 약 → 5일 강).

- **반응 시간(UCN 2.1s 변형):** 윤진이 “근접 경고” 낸 뒤 플레이어가 멈출 유예. 후반 날 짧아짐. (전진 안 누르면 안전하므로 사실상 “근접 중 전진 금지 구간”의 길이)

- **스테레오 음악(공통):** 좌/우/거리로 위치 파악 = 윤진 정체성.

- **버린 것:** 문 닫기(UCN), 좌우 복도 선택, 카메라 비활성 — 우리 한 방향 통과엔 무관.

## 5.4 진행 흐름

창고 진입(freeze 시작) 
  → [반복] 윤진 소리 청취 
      → 멀면 전진 입력 / 가까우면 정지 대기
  → 창고 통과 → 전기실 도착(윤석 구간)
  → 수리 → 관리실 복귀(freeze 해제)

## 5.5 필요 애니메이션 / 사운드

| # | 애니메이션 | 용도 |
| --- | --- | --- |
| H1 | (1인칭) 기어가기 전진 모션 | 이동 입력 |
| H2 | 윤진 점프스케어(어둠 속에서 덮침) | 근접 중 전진 |
| # | 사운드 | 트리거 |

# 6. 장윤석 (전기실 브레이커 / SL Breaker Room — Funtime Freddy)

창고런 2단계(윤진 통과 후). SL 둘째 밤 Breaker Room 충실 이식. **스파크로 위치 확인 + 4단계 접근 + 위험도 줄다리기.** 윤진(청각)와 대비되는 **시각 + 패널 조작** 막.

## 6.1 개요

- **등장:** 4일차~. 전기실. 창고런에서 윤진 통과 후 도착.

- **목표:** 브레이커 **3개**(공부방 전원 / 로비·화장실 전원 / 관리실 전원) 복구 → 정전 해제 → 3막 탈출.

- **당하면:** **즉사**(심기 최대 + 윤석 최종 단계에서 모니터 내릴 때).

- **톤(연출만):** 장난기·웃음기 많던 친구 → 웃음/키득거림/웃으며 덮침. 메커니즘 미반영.

## 6.2 두 화면 구조 (원작)

- **패널 화면:** 브레이커 3개 RESTART(클릭&홀드) + **위험도 게이지** 표시.

- **방 전경(전기실):** 평소 깜깜. **스파크가 튈 때만** 그 순간 윤석 실루엣이 보임 → 위치 확인.

- 플레이어는 이 둘을 오가며 진행(모니터 올림=패널 / 내림=전경).

## 6.3 핵심 메커니즘 (위험도 줄다리기)

- **전기 올림(RESTART 홀드) 중:** 위험도(심기) **상승**.

- **윤석 4단계 접근:** 위험도가 높을수록 윤석이 4개 위치(전기실 오른쪽 앞/뒤, 왼쪽 앞/뒤)로 **단계적으로 다가옴.** **스파크 순간에만** 어느 단계인지 보임.

- **위험도 하락:**

- **패널 내림(일 멈춤)** → 위험도 서서히 하락 → 윤석 후퇴.

- **달래기 버튼(스페이스)** → 추가 리셋(원작 soothing 방식 — 누르면 충전, 모니터 내린 상태 특정 시점 확률로 위험도 리셋).

- **죽음:** 위험도 최대 + 윤석 최종 단계 도달 상태에서 **모니터 내릴 때** 즉사. (올린 동안 유예)

- **최소 시간 보장:** 위험도 최대까지 최소 N초 → 운으로 즉사 안 함(공정).

## 6.4 진행 흐름

(윤진 창고 통과) → 전기실 도착
  → [반복] 패널 열고 브레이커 RESTART(위험도↑, 윤석 다가옴)
      → 방 전경 스파크로 윤석 위치 확인
      → 위험하면 패널 내림 + 달래기(스페이스) → 위험도↓, 윤석 후퇴
  → 브레이커 3개 모두 복구
  → 정전 해제 → 3막(윤진 창고 탈출) → 관리실 복귀(freeze 해제)

## 6.5 danger level (원작 차용, 표시용)

현재 “지금 뭐 하는 중” 표시(윤석 거리 아님): 패널 닫힘=1 / 열림=2 / 브레이커 복구중=3.

## 6.6 압축 (원작 8섹터 → 3개)

원작이 길었던 건 복구 섹터가 많아서(8개). 우리는 **3개**로 메커니즘(스파크·4단계·달래기)은 그대로, 횟수만 단축. 한 번 한 번은 원작만큼 쫄깃, 사이클 3번.

# 7. 준영 (팬텀 포시 / 관리실 갑툭튀)

7번째 귀신. FNAF3 팬텀 포시 로직 거의 직수입. **AI 없음** — 그날 출현 여부만 확률로 결정, 하루 최대 1회.

## 7.1 개요

- **등장:** 3일차~ (확률). 이동·AI 없음.

- **작동:** 어느샌가 **관리실 구석에 나타나 있음.** **시간 내에 카메라(CCTV)를 켜면** → 사라짐(회피). **하지만 또 나옴 → 점프스케어 당할 때까지 반복 등장.**

- **“하루 1회” = 점프스케어 1회.** 점프스케어 성공(교란) 후에야 그날 완전히 퇴장. 그 전까지 계속 깐족대며 재등장.

- **결과:** 교란형(즉사 아님) → **환기 오류 ON**(김욱과 동일). 회피는 “이번 등장을 넘긴 것”일 뿐, 결국 한 번은 막기 어려움.

## 7.2 출현 확률 (원작 표 → 5일 매핑)

| 밤 | 확률 |
| --- | --- |
| 2일 | 1/1000 (사실상 없음) |
| 3일 | 1/50 |
| 4일 | 1/25 |
| 5일 | 1/10 |

“그날 나올지”를 위 확률로 판정 → 나오면 **점프스케어 당할 때까지 반복 등장**(회피해도 또 나옴), 점프스케어 1회 후 그날 퇴장. 3일차는 위 값보다 더 낮게(첫 등장이라 가끔만).

## 7.3 메커니즘 (김욱과 정반대)

- **김욱(BB):** 카메라 **안**에 떠 있음 → 카메라에서 **벗어나야** 안전(끄기/전환).

- **준영(포시):** 카메라 **밖**(관리실 구석)에 떠 있음 → **카메라를 켜야** 안전.

- 둘 동시 활성 시 “켜라 vs 꺼라” 순간 갈등 → 압박.

- **반응 시간:** 관리실에 나타난 뒤 제한시간(후반 짧아짐) 내 카메라 ON 안 하면 공격.

## 7.4 교란 결과 = 환기 오류

점프스케어 당하면 **환기 오류 ON**(김욱과 동일 결과, 중첩 없음 on/off 하나). 화면 흐려짐 주기 반복 → armed 귀신 공격 기회. 리셋으로 복구. 유발 경로만 김욱(카메라)과 다름(관리실 구석).
